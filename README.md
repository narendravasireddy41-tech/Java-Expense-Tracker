# Java Expense Tracker

A console-based Expense Tracker application developed using Java. This project helps users manage daily expenses, calculate totals, and view spending summaries.

## Features

* Add new expenses
* View all expenses
* Search expenses using ID
* Delete expenses
* Calculate total expenses
* Category-wise expense summary
* Monthly expense report
* Input validation for month and year
* Save expense data using file handling
* Load previously saved expenses when the application starts

## Technologies Used

* Java
* ArrayList
* HashMap
* File Handling
* Scanner
* Object-Oriented Programming

## How to Run

### Step 1: Compile

```bash
javac Main.java Expense.java
```

### Step 2: Execute

```bash
java Main
```
